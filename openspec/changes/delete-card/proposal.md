## Why

На доске нет способа убрать карточку — ни ошибочно созданную, ни просто ненужную. Однажды добавленная карточка остаётся навсегда, что затрудняет управление содержимым доски.

## What Changes

- У каждой карточки появляется элемент управления для удаления.
- Удалённая карточка пропадает с доски без перезагрузки страницы.
- Удаление карточки отправляет запрос на сервер — после перезагрузки страницы удалённая карточка не возвращается.
- Подтверждение перед удалением не требуется — удаление выполняется одним действием.

## Capabilities

- `card-deletion`: удаление карточки с доски и синхронизация с сервером.
