## Context

В текущей ветке `BoardCard` получает только `title` и `isDone` — без `id` и без обработчика удаления. `BoardColumn` рендерит карточки через `.map()` и не передаёт callbacks. `App.tsx` использует React Query с `useQuery` для загрузки и `useMutation` для создания. `api/cards.ts` содержит `fetchCards` и `createCard` — функции удаления нет.

## Goals

- У каждой карточки — видимый элемент удаления.
- Нажатие удаляет карточку с доски без перезагрузки.
- Удаление отправляется на сервер — после `F5` карточка не возвращается.
- Остальные карточки не затрагиваются.

## Decisions

### Decision 1: Где обрабатывать удаление

**Вариант A — Обработчик в App.tsx (выбрано)**

`App.tsx` хранит состояние карточек через React Query. Обработчик удаления вызывает `useMutation` и инвалидирует кэш. `BoardColumn` и `BoardCard` получают `onDelete(id)` как prop.

*Плюсы:*
- Централизованная логика — всё управление карточками в одном месте.
- `invalidateQueries` автоматически обновляет доску.
- Соответствует паттерну, уже использованному в `NewCardForm`.

*Минусы:*
- Нужно пробросить `onDelete` через `BoardColumn` до `BoardCard`.

**Вариант B — Обработчик в BoardCard**

`BoardCard` сам вызывает `fetch('/api/cards/:id', { method: 'DELETE' })` и обновляет DOM.

*Плюсы:*
- Карточка автономна — не нужно пробрасывать props.

*Минусы:*
- Дублирование логики с `NewCardForm` (там уже используется `useMutation`).
- Нет единого места управления — сложнее отлаживать.
- Нужно обходить React Query кэш вручную.

**Выбор:** Вариант A. Удаление — часть общего цикла CRUD карточек, логика должна быть централизована в `App.tsx`.

### Decision 2: Подтверждение удаления

**Вариант A — Без подтверждения (выбрано)**

Удаление выполняется одним кликом по кнопке.

*Плюсы:*
- Соответствует спецификации: «без диалога подтверждения».
- Быстрое действие — пользователь не делает лишних шагов.
- Минимум кода.

*Минусы:*
- Риск случайного удаления.

**Вариант B — Диалог подтверждения**

`window.confirm('Удалить карточку?')` перед удалением.

*Плюсы:*
- Защита от случайного клика.
- Пользователь видит, что действие необратимо.

*Минусы:*
- Блокирует поток — лишний шаг.
- Не соответствует спецификации задания.
- `window.confirm` блокирует основной поток.

**Выбор:** Вариант A. Спецификация явно описывает удаление без диалога — одним действием.

### Decision 3: Стратегия обновления UI

**Вариант A — Invalidация кэша (выбрано)**

После успешного DELETE вызывается `queryClient.invalidateQueries({ queryKey: ["cards"] })`. React Query перезагружает карточки с сервера.

*Плюсы:*
- UI всегда синхронизирован с сервером.
- Нет рассинхронизации — данные берутся из источника правды.
- Паттерн уже используется в `NewCardForm`.

*Минусы:*
- Короткая задержка до перезагрузки данных (зависит от скорости сервера).

**Вариант B — Оптимистичное обновление**

Карточка мгновенно удаляется из UI, запрос на сервер идёт асинхронно. При ошибке — откат.

*Плюсы:*
- Мгновенная реакция UI.
- Лучшее ощущение отзывчивости.

*Минусы:*
- Сложнее: нужен `onMutate`, `onError`, `rollback`.
- Риск рассинхронизации при ошибке сервера.
- Избыточно для текущего масштаба проекта.

**Выбор:** Вариант A. Для задачи «удаление карточки» достаточно инвалидации — сервер гарантированно актуален, задержка незаметна.

## Plan

1. **api/cards.ts** — добавить `deleteCard(id: string)`: DELETE `/api/cards/:id`.
2. **types/card.ts** — убедиться, что `Card.id` доступен в `BoardCard` (сейчас не передаётся).
3. **BoardCard.tsx** — добавить `id` и `onDelete` в props, отрисовать кнопку удаления.
4. **BoardCard.module.css** — стили для кнопки удаления.
5. **BoardColumn.tsx** — передать `id` и `onDelete` в `BoardCard`.
6. **App.tsx** — добавить `useMutation` для удаления, передать `onDelete` в `BoardColumn`.

## Impact

- `client/src/api/cards.ts` — новая функция `deleteCard`.
- `client/src/types/card.ts` — `id` пробрасывается до `BoardCard`.
- `client/src/components/BoardCard/BoardCard.tsx` — props `id`, `onDelete`, кнопка удаления.
- `client/src/components/BoardCard/BoardCard.module.css` — стиль кнопки.
- `client/src/components/BoardColumn/BoardColumn.tsx` — передача `id` и `onDelete`.
- `client/src/App.tsx` — `useMutation` для удаления, `onDelete` callback.
