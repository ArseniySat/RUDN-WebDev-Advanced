# card-deletion Specification

## Purpose
Пользователь может удалить карточку с доски одним действием — без подтверждения и перезагрузки страницы. Удаление отправляется на сервер и сохраняется после перезагрузки.

## Requirements

### Requirement: Элемент управления удалением у каждой карточки
У каждой карточки на доске присутствует видимый элемент управления для удаления.

#### Scenario: Кнопка удаления видна на карточке
- **WHEN** карточка отображается на доске
- **THEN** рядом с названием карточки виден элемент управления удалением

### Requirement: Удаление без перезагрузки страницы
Система удаляет карточку из интерфейса сразу после нажатия элемента управления, без перезагрузки страницы.

#### Scenario: Карточка пропадает после нажатия кнопки удаления
- **WHEN** пользователь нажимает элемент управления удалением на карточке
- **THEN** карточка немедленно исчезает с доски

### Requirement: Удаление синхронизируется с сервером
Система отправляет запрос на удаление карточки на сервер. После перезагрузки страницы удалённая карточка не возвращается.

#### Scenario: Удалённая карточка не возвращается после F5
- **WHEN** карточка удалена и страница перезагружена (`F5`)
- **THEN** удалённая карточка не отображается на доске

### Requirement: Удаление выполняется без подтверждения
Удаление карточки выполняется одним действием — без диалога подтверждения.

#### Scenario: Карточка удаляется по клику без диалога
- **WHEN** пользователь нажимает элемент управления удалением на карточке
- **THEN** карточка удаляется немедленно, без показа диалога подтверждения
